# 版式规格

## 页面

A4。上边距 2.8cm，下边距 3.2cm，左右各 2.5cm，页眉页脚边距 1.27cm。

可用正文高度约 23.7cm，封面各段高度之和必须小于这个值。

## 样式对照

模板样式表用数字 ID。写自定义 XML 时按此对照：

| 用途 | styleId | 字体 | 字号 | 说明 |
|---|---|---|---|---|
| 正文 | `1` | 仿宋 | 16pt | 固定行距 30pt，首行缩进 2 字符 |
| 一级标题 | `3` | 黑体 | 16pt | 与下一段同页 |
| 二级标题 | `4` | 楷体 | 16pt | |
| 目录一级 | `26` | 楷体 | 16pt | 右对齐点线制表位 |
| 目录二级 | `29` | 楷体 | 16pt | 加左缩进 |
| 表格 | `35` | 仿宋 | 10.5pt | |
| 页脚 | `24` | 宋体 | 8.5pt | 「— 页码 —」居中 |

## 字体

四类中文字体随文档嵌入，并为每个字体配置回退名，防止目标机器缺字体时整篇显示方块：

| 用途 | 首选字体 | 回退 |
|---|---|---|
| 正文 | 仿宋 | 系统仿宋 |
| 一级标题 | 黑体 | 系统黑体 |
| 二级标题 | 楷体 | 系统楷体 |
| 封面标题 | 大标宋 | 宋体 |

**每处文字都要显式指定中文字体。** 依赖主题字体会落到一个不存在的字体上。

## 封面

- 大标题：大标宋 36pt 加粗居中，**单倍行距**。字号大于行高时固定行距会压字
- 其余空段用 30pt 固定行距，便于按段数核算高度
- 信息行：楷体 22pt 居中，三行——编制人、编制单位、编制日期
- 换算：空段 30pt，标题行单倍约 43pt。4×30 + 2×43 + 7×30 + 3×30 + 1×30 ≈ 536pt ≈ 18.9cm，单页可容纳

## 表格

与正文同宽，居中，全框线 0.5pt，固定列宽。首行加粗、跨页重复。单元格段落固定行距、无首行缩进。

## 题注

```
表 N　题名        ← 黑体 9pt 居中，在表格上方
图 N　题名        ← 黑体 9pt 居中，在图片下方
```

编号与题名之间用全角空格分隔。题注段落取消首行缩进，**紧贴对象，中间不插空段落**。

## 分页

只用两种分页方式，总数固定 2：封面末尾、目录末尾。

不要用「段前分页」，不要连续两次分页——那会产生空白页。

## 图片

上下环绕，水平居中，垂直偏移 0。

图片所在段落用**单倍行距、零段前段后**。写成固定行距时，段落先占掉一整行高度，图片再从图下方环绕，看起来就像题注浮在图上面。

插入宽度取约 9.7cm 时，竖版长图可单页放下。插入宽高比必须等于 PNG 实际宽高比，否则图被压扁。
